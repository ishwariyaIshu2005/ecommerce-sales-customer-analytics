# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview
This project analyzes e-commerce sales data to understand sales performance, profitability, product category trends, and regional performance. An interactive Power BI dashboard was developed to present key metrics and business insights.

## Objectives
- Analyze sales and profit performance.
- Identify high-performing product categories and regions.
- Understand monthly sales trends.
- Develop KPIs and an interactive business dashboard.

## Tools & Technologies
- Microsoft Excel
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI and DAX

## Project Workflow
1. Inspected and cleaned the e-commerce datasets.
2. Checked missing values, duplicate order IDs, invalid dates, and unusual data values.
3. Analyzed sales, profit, quantity, and order performance.
4. Connected Orders data with Customers and Products tables.
5. Created KPI measures and developed Power BI visualizations.
6. Summarized key business insights from the dashboard.

## Key Business Insights
- Electronics recorded the highest sales among categories.
- South recorded the highest sales among regions.
- Electronics generated the highest profit among categories.
- January had the highest monthly sales, while December had the lowest.
